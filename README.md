# Neon Run — South Beach, 1986

A tiny, original top-down open-world driving game with a sun-bleached coastal city, pastel rooftops, 80s night-drive colors, traffic, police chases, and repeatable courier runs.

## Play

Open `index.html` in a modern browser. No install, build step, account, or server is required.

- **WASD / arrow keys:** walk or drive
- **E:** enter the nearest car or get out
- **Space:** handbrake while driving
- **P:** pause
- **New Run:** restart from the opening block

Find the pink marker, collect the envelope, and deliver it to the next marker for cash. Crashing at speed draws police attention. Lose the patrol or keep moving until your heat fades.

The city and vehicle art are drawn in Canvas at runtime. There are no bundled image assets or game engine dependencies; optional Google Fonts fall back to system fonts when unavailable.
